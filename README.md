# 即译

Chrome / Edge 浏览器扩展：用你自己的 **OpenAI 兼容** 模型，实时翻译网页正文。API Key 只保存在本机。

## 安装

1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）
2. 打开右上角 **开发者模式**
3. 点 **加载已解压的扩展程序**，选中本目录
4. 改过代码后，在扩展卡片上点 **重新加载**，再刷新要翻译的网页

本地检查：

```bash
node scripts/check.mjs
```

## 配置模型

在扩展图标上右键 → **选项**，或弹窗里点 **设置**。

需要填写：

- **Base URL**：兼容 OpenAI Chat Completions 的根路径，例如 `https://api.x.ai/v1`
- **API Key**：本地服务（如 Ollama）可留空
- **模型名**：例如 `grok-4.5`

预设可一键填入 SpaceXAI / OpenAI / OpenRouter / DeepSeek / AIHubMix / Ollama。点 **测试连接** 确认可用。

Base URL 填到 `/v1` 即可，不要带 `/chat/completions`。

设置支持导出 / 导入 JSON（含 API Key，请自行保管）。

## 使用

- 弹窗点 **翻译此页**，视口内文本会先译，其余随滚动或空闲补上
- 页面浮层可看进度，支持暂停、重试、还原、隐藏
- 勾选 **以后打开此网站自动翻译** 后，该站点会在加载时自动开始
- 勾选 **永不翻译此网站** 后，该域名及其子域都会跳过
- 右键可选 **翻译选中文本** / **翻译整个页面** / **翻译输入框内容**
- 快捷键：`Alt+Shift+Y` 翻译或还原；选区与输入框快捷键可在 `chrome://extensions/shortcuts` 自行绑定
- 聚焦输入框时，右上角会出现 **译** 按钮，把当前内容译成目标语言
- 选中文本的译文气泡支持 **复制** 和 **替换选区**

动态插入的内容（评论、无限滚动、多数 SPA）会由页面监听继续翻译。同源 iframe 也会尝试翻译；过小的广告框会被跳过。

## 翻译行为

- 默认跳过代码块、纯数字、URL、邮箱，以及已经很像目标语言的句子
- 可选对照显示、悬停查看原文、翻译页面标题和 `alt` / `placeholder` 等属性
- 可用术语表锁定专有名词译法
- 可用 CSS 选择器跳过指定区域
- 译文按模型 / 语言 / 提示词哈希缓存到本机，上限 1200 条

## 权限说明

- `storage`：保存设置与译文缓存
- `contextMenus`：右键菜单
- `scripting` + `<all_urls>`：在网页中替换文本，以及请求你配置的模型接口
